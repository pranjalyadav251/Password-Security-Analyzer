# Password Security Analyzer & Generator

A web-based tool built with HTML, CSS and JavaScript.

## Features
- Password strength rating out of 5
- Live rules checklist (length, capital, small, number, symbol)
- Entropy and estimated crack time
- Common password detection
- Secure password generator (uses crypto.getRandomValues)
- Copy button and one-click "Check" to analyze generated passwords

## Privacy
Everything runs in the browser. No password is stored or sent anywhere.

HTML, CSS, JavaScript
